## Konsole Color Scheme

`KonsoleBreezeDark.colorscheme` — A Breeze-inspired dark color scheme for the Konsole terminal emulator.

### How to apply

1. Copy the file to your Konsole color schemes directory:
   ```bash
   cp KonsoleBreezeDark.colorscheme ~/.local/share/konsole/
   ```
2. Open Konsole → **Settings** → **Edit Current Profile** → **Appearance**.
3. Select **Breeze Dark** from the color scheme list and click **OK**.
